# Mantle 1.21.1 NeoForge port

This branch ports Mantle to Minecraft 1.21.1 and NeoForge.

The source-level API migration uses the MIT-licensed Modern-Mods/Hilt
`Neo/1.21.1` implementation as a reference and implementation lineage.
Hilt itself carries forward Mantle architecture while adapting it to
modern NeoForge APIs. Mantle package names, mod ID, and project identity
are retained here for compatibility with SlimeKnights/TinkersConstruct.

Reference: https://github.com/Modern-Mods/Hilt/tree/Neo/1.21.1
Original Mantle: https://github.com/SlimeKnights/Mantle
